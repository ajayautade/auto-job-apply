Setup Guide

1. Gemini API Key Not Set

Get your free API key from Google AI Studio and add it to the .env file.

2. Gmail App Password Not Set

  1. Enable 2-Factor Authentication on your Google account
  2. Go to App Passwords
  3. Create an App Password for "Mail"
  4. Add it to the .env file

3. Your Details

Update YOUR_NAME, YOUR_EMAIL, YOUR_PHONE, etc. in the .env file for personalized emails.

GEMINI_API_KEY=your_key
GMAIL_USER=your@gmail.com
GMAIL_APP_PASSWORD=xxxx xxxx xxxx xxxx
YOUR_NAME=Your Name
YOUR_PHONE=+91 XXXXXXXXXX
